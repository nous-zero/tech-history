## 📐 문서 표준 템플릿

모든 기술 항목은 아래 6개 필드로 기록한다.

```markdown
## [연도] 기술명
- 문제: 무엇이 안 됐는가
- 해결: 누가, 무엇으로 풀었는가
- 원리: 한 문장 핵심
- 새로운 문제: 이 해결이 낳은 부작용
- 현재: 지금도 쓰이는가 / 무엇으로 대체됐는가
- 출처: 검증 링크 1개 이상
```

## ✍️ 작성 원칙

1. **출처 없는 서술 금지** — 항목당 검증 가능한 출처 1개 이상.
2. **추론·개인 관찰은 명시** — 사실과 구분해 표기.
3. **본문은 주제(서사)로, 문서 상단에는 연도순 타임라인 표** — 콘텐츠용과 참조용을 모두 만족.
4. **수치는 폭으로 표현** — 출처마다 다른 점유율 등은 단정하지 않는다.
