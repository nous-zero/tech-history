**한 줄 요약: 오늘 데이터 수집 실패 — 유튜브 접속 열쇠(OAuth 인증 토큰)가 만료·폐기되어 사용자가 다시 인증해야 함. 마지막 확보 데이터는 11일 전(2026-08-02) 기준.**

## 수집 결과: 실패(미확인)

- 실행: `YT_TOKEN_PATH=<yt-keys>/youtube_oauth_token.json python video/fetch_analytics.py`
- 오류 원문(그대로 기록, 지어내지 않음):
  ```
  google.auth.exceptions.RefreshError: ('invalid_grant: Token has been expired or revoked.',
  {'error': 'invalid_grant', 'error_description': 'Token has been expired or revoked.'})
  ```
- 쉬운 설명: "OAuth 인증 토큰"은 우리 프로그램이 유튜브 데이터에 접근할 때 쓰는 일종의 "출입증"이다. 이 출입증이 만료되거나(오래 안 씀) 누군가 취소해서, 프로그램이 문을 못 열고 있다. 자동으로 새 출입증을 발급받는 절차(refresh)도 실패했다 — 즉 사람이 브라우저로 다시 로그인해서 새 출입증을 발급해야 한다.
- 참고: `yt-keys` 저장소의 열쇠 자체는 정상 확인됨(파일 존재, 필요한 권한 범위 `yt-analytics.readonly` + `youtube.readonly` 명시됨). 저장소 접근 문제가 아니라 **토큰 자체의 유효기간/폐기 문제**.
- 새 snapshot/private JSON 파일은 생성되지 않음(오늘자 실측 지표 0건 — 지표를 지어내지 않음).
