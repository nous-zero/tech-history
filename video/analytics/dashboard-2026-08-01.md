## 문제점 (관찰된 것만)

1. **채널 총 조회수 +81% 헤드라인은 실제 성장이 아닐 가능성 큼(추정)** — 채널 API 총계(5,987→10,850, +4,863)가 영상별 합계 증가분(+795)보다 6배 이상 크게 뛰었다. 그동안 나흘째 벌어지던 "채널 총계 < 영상별 합계" 격차(-1,783→-2,686→-4,521)가 오늘 -453으로 급격히 좁혀진 것과 정확히 맞물림 — 즉 어제까지의 채널 총계 표시값 자체가 지연·과소 캐시였고, 오늘 그 캐시가 실제 값으로 보정되며 숫자가 튄 것으로 추정. 실제 신규 조회는 영상별 합계 기준 +795건(+7.6%)이 더 신뢰할 지표.
2. **videoCount API 값이 10→3으로 급락**(실제 영상 목록은 12개로 그대로) — 어제는 실제와 격차 2였는데 오늘은 9로 악화. 원인 미확인.
3. **시청 유지율(averageViewPercentage) 3일 연속 하락**: 7/27 79.22% → 7/28 70.04% → 7/29 61.10%. 추정: 최근 업로드(CERN·Netscape 시리즈)의 초반 후킹이 첫 주보다 약해짐.
4. **롱폼 4편 모두 여전히 조회수 한 자릿수~20대**(20/29/19/20회) — 같은 날 쇼츠(수백~수천 회)와 격차 그대로. ARPANET 영상(aPR3TsM9Rls)은 유지율도 25.59%로 전체 최저.

2. videoCount 급락 → 스튜디오에서 비공개 전환·멤버십 전용·삭제예약 영상이 있는지 확인.
