## 문제점 (관찰된 것만)

1. **쇼츠 4편이 하루 만에 +33%~+455% 급등** — 특히 "웹 승인 도장" 쇼츠(208→1,154, +454.8%)와 신규 "Netscape 28→71달러" 쇼츠(첫날 2,425회)가 두드러짐. 영상별 트래픽소스 데이터가 아직 안 잡혀 정확한 유입 경로 확인 불가(추정: 유튜브 쇼츠 추천 피드 확산 — 채널 전체 유입의 96.7%가 SHORTS 경로임).
2. **채널 총계 vs 영상별 합계 불일치가 나흘째 더 벌어짐** — 어제도 지적했던 문제인데 격차가 -2,686(어제)에서 -4,521(오늘)로 거의 두 배로 확대됨. 단순 집계 지연으로 보기 어려운 규모(추정: 구조적 차이 또는 API 값 자체의 신뢰도 문제).
3. **videoCount 불일치도 나흘째 지속, 격차 확대** — API 통계(10)와 실제 영상 목록(12) 차이가 어제(1개)보다 커짐(2개). 비공개·멤버십·삭제예약 영상 존재 가능성(추정).
4. **조회수는 크게 늘어도 구독 전환은 미미함** — 전일 대비 조회수 +2,767 늘었는데 구독자는 +2(4→6)에 그침. 사흘 연속 지적된 문제 반복.
5. **일반 영상(긴 영상)은 여전히 조회수 한 자릿수~10대대 수준** — LO(17), TCP/IP(18), CERN(16), 신규 Netscape(7) 모두 같은 날 쇼츠(수백~수천 회)와 격차가 크다. 나흘째 반복되는 패턴.

## 보완점 (문제당 행동 1개)

1. 급등 원인 불명 → 영상별 traffic_sources가 채워지면(현재 6개 구영상만 반영) 어떤 쇼츠가 추천 피드를 탔는지 특정해 같은 훅·편집 패턴을 후속 쇼츠에 재사용.
2. 채널·영상 합계 불일치 확대 → 나흘째 격차가 커지고 있어 더 이상 "집계 지연"으로 보기 어려움. YouTube Studio 콘솔에 직접 로그인해 채널 총 조회수를 API 값과 대조 검증 권장(우선순위 상향).
3. videoCount 불일치 확대 → 스튜디오에서 비공개·멤버십 전용·삭제예약 영상이 있는지 직접 확인.
4. 구독 전환 저조 → 어제 올라간 Netscape 롱폼·쇼츠 3편에 아직 "구독하면 다음 편 먼저 봄" CTA가 적용됐는지 확인하고, 안 됐다면 오늘부터 신규 업로드에 바로 적용.
5. 긴 영상 노출 부족 → 신규 Netscape 롱폼 설명란 첫 줄에 같은 날 쇼츠 2편 링크 삽입 + 쇼츠 고정댓글에 롱폼 링크 추가.
