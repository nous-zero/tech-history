## 수집 결과: 실패(미확인) — 어제와 동일 원인, 미해결 지속

- 사전 준비: `pip install google-api-python-client google-auth google-auth-httplib2` — 성공. 추가로 환경 문제(`_cffi_backend` 모듈 누락)가 있어 `cryptography`/`cffi` 재설치로 해결.
- 실행: `YT_TOKEN_PATH=<yt-keys>/youtube_oauth_token.json python video/fetch_analytics.py`
- 오류 원문(그대로 기록, 지어내지 않음):
  ```
  google.auth.exceptions.RefreshError: ('invalid_grant: Token has been expired or revoked.',
  {'error': 'invalid_grant', 'error_description': 'Token has been expired or revoked.'})
  ```
- 쉬운 설명: "OAuth 인증 토큰"은 우리 프로그램이 유튜브 데이터에 접근할 때 쓰는 "출입증"이다. 어제 이 출입증이 만료·폐기된 것을 확인했는데, 오늘도 여전히 같은 출입증이 저장소(`yt-keys`)에 그대로 있다 — 즉 아직 아무도 새로 로그인해서 출입증을 갱신하지 않았다는 뜻이다.
- 참고: `yt-keys` 저장소 자체 접근은 정상(파일 존재, 권한 범위 `yt-analytics.readonly` + `youtube.readonly` 명시). 저장소 문제가 아니라 **토큰 유효기간/폐기 문제가 이틀째 계속됨**.
- 새 snapshot/private JSON 파일 생성 안 됨(오늘자 실측 지표 0건 — 지표를 지어내지 않음).
