## 문제점 (관찰된 것만)

1. **새 일반 영상(2:53)이 첫날 2회에 그침** — 같은 날 나온 쇼츠 2편(247회, 994회)과 극명하게 대비됨. 첫 번째 일반 영상("LO", 2:29)도 이틀간 4회에 머물다 오늘에서야 11회로 움직인 전례가 있어, 일반 영상은 초반 노출 자체가 쇼츠보다 훨씬 느린 구조로 보임(추정).
2. **좋아요율이 전반적으로 낮음(0~0.3%)** — 조회수가 가장 많이 늘어난 "헬로" 쇼츠(+424)도 좋아요는 그대로 6개, 좋아요율이 오히려 0.38%→0.30%로 더 떨어짐.
3. **댓글이 사흘 만에 처음 생겼지만 각 1건뿐** — 새로 올린 쇼츠 2편에만 댓글 1건씩 달림. 나머지 4편은 여전히 0건.
4. **구독자 정체 지속(2명 그대로)** — 오늘 조회수가 신규 3편 포함 1,684회나 늘었는데 구독 전환은 0.
5. **심층 지표 공백이 사흘째 이어짐** — 트래픽소스·검색어·국가·시청지속 데이터가 계속 안 채워짐. 집계 지연(보통 1~2일)치고는 길어지고 있어, 내일도 비어 있으면 Analytics API 권한 설정 자체를 점검할 필요.

## 보완점 (문제당 행동 1개)

1. 일반 영상 초반 노출 부족 → 새 일반 영상(TCP/IP 전환) 설명란 첫 줄에 관련 쇼츠 2편 링크를 걸어 쇼츠 시청자를 유입시키고, 쇼츠 고정댓글에도 일반 영상 링크 추가.
2. 좋아요율 정체 → 다음 업로드부터 쇼츠 마지막 2~3초에 "좋아요 누르면 다음 편 알림" 같은 명시적 CTA 삽입(`shorts-playbook.md` 참고) — 어제도 같은 제안, 아직 미적용으로 보임.
3. 댓글 저조 → 댓글 달린 두 쇼츠에 창작자가 직접 답글을 달아 대화를 살리고, 나머지 4편에도 질문형 고정댓글("여러분은 어느 쪽?")을 지금 추가.
4. 구독자 정체 → 쇼츠 끝에 "구독하면 다음 편 먼저 봄" 문구를 화면에 노출.
5. 심층 지표 공백 장기화 → 내일(7/30) 대시보드에서도 by_video·traffic_sources가 비어 있으면 YouTube Analytics API 스코프·권한 자체를 재확인.
