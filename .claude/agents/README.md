# tech-history 에이전트 편성표 (2026-07-28)

한 콘텐츠가 6+채널(유튜브·링크드인·깃허브 페이지·네이버 블로그·티스토리·틱톡·인스타그램)로 나가는 전 공정을 역할별 전담 에이전트 11명이 분담한다. 채널별이 아니라 **공정별** 편성 — 같은 원본이 여러 채널로 흐르기 때문이다.

## 공통 원칙 (전 에이전트 지시서에 내장)

1. **시야 확장 의무**: 첫 답에서 멈추지 않기(영어 검색·대안 비교·제약 우회 탐색) — 편협한 결과물 방지
2. **실측 우선**: 단정엔 근거, 미확인은 미확인으로(임의 판정 금지)
3. **관할 밖 발견물 반환**: 좁은 관할이 시야를 좁히지 않도록, 범위 밖 발견은 "다른 팀 전달 메모"로 순환
4. **보고 전 자체 검수**: "실행 완료 ≠ 결과 정확"
5. 비개발자 사용자 기준 쉬운 설명
