# 무료·상업이용 가능 미디어 소스 총람 (2026-07-28 실측 조사)

asset-scout(소재 조달)·copyright-counsel(저작권 검수) 에이전트의 공용 지식 베이스.
검증 표기: ✅=공식 페이지 직접 확인 또는 2개 이상 독립 출처 교차 / ⚠️=2차 출처 기반 / ❓=미검증(사용 전 재확인 필수).
용어: PD=퍼블릭 도메인(저작권 소멸 — 자유 사용) / CC0=저작권 완전 포기 / CC-BY=출처 표기 시 자유 / CC BY-NC=비상업 전용(수익 영상 불가).

## 2. 현대 스톡 영상·이미지

- **Pexels** ✅ pexels.com/license — 상업 OK·표기 불요. 무수정 재판매·인물 부정 연출 금지.
- **Pixabay** ✅ — Content License(2023년 CC0→자체 변경). 상업 OK·표기 불요. 파일 단독 재배포 금지.
- **Videvo** ✅ — 혼합: 무료 클립 상당수 **Attribution 라이선스**(표기 의무 "Video by [작성자] on Videvo") — 클립별 라벨 확인.
- **Coverr** ✅ / **Mixkit** ✅ — 상업 OK. Mixkit은 Restricted 표시 항목=비상업 전용, 음악은 방송·게임 불가(유튜브·SNS OK).
- **Unsplash** ✅ — 상업 OK·표기 불요. 함정: 검색 결과에 유료 Unsplash+ 이미지 혼입 — 다운로드 전 구분.
- **Openverse** ✅ — CC 통합검색기. 메타데이터 오류 가능 — **원 출처에서 라이선스 재확인 필수**.

## 3. 음악 — 플랫폼 함정이 가장 큰 카테고리

| 소스 | 상업 | 표기 | 전 플랫폼 사용 |
|---|---|---|---|
| YouTube Audio Library ✅ | 유튜브 수익화 OK | CC-BY 트랙만 | **유튜브 한정으로 보는 게 안전** — 틱톡·릴스·팟캐스트 재사용 비권장 |
| **Pixabay Music ✅ — 기본값** | 예 | 불요 | **예(전 플랫폼)** — 라이선스가 소스에서 나오므로. 음원 단독 배포만 금지 |
| Mixkit Music ✅ | 예 | 불요 | 유튜브·SNS·팟캐스트 OK / CD·방송·게임 불가 |
| Incompetech(Kevin MacLeod) ✅ | 예 | **필수**(CC-BY) | 예. $30로 표기 면제 구매 가능 |
| Free Music Archive ✅ | 트랙별 | 트랙별 | **BY-NC 다수 혼재** — CC-BY/PD 필터 필수 |

**핵심 규칙** ✅: 틱톡·인스타 **비즈니스/상업 계정은 일반 음악 라이브러리 금지**(상업용 CML/Meta Sound Collection만). 그리고 플랫폼 라이브러리 음원 권리는 **그 플랫폼 안에서만 유효** — 크로스포스팅 시 무단 사용이 됨. **해법: 소스에서 라이선스가 나오는 음악(Pixabay·Mixkit·CC-BY·자체 생성 ACE-Step)을 영상에 구워 넣어 전 플랫폼 동일 파일 배포.**

## 5. 라이선스 검증 워크플로 (에이전트 필수 절차)

1. **Wikimedia 파일 검증**: 파일 상세 페이지에서 ①라이선스 태그 ②출처 링크 생존 ③업로더≠저작자 확인. 링크가 죽었으면 Wayback으로 원 출처 복원 확인. `{{Not-PD-US-URAA}}` 태그=미국에선 저작권 존속.
2. **PD 이중 판정**: 유튜브는 전 세계 배포 → **미국·한국 양쪽 PD(또는 CC0)만 '안전' 판정**. 미 정부 저작물·CC0 기관 공개분=안전, 1920~50년대 민간 작품=건별 확인.
3. **CC-BY 표기=TASL**: Title·Author·Source(URL)·License(명+링크). 예: `"Track" by Kevin MacLeod (incompetech.com), CC BY 4.0` — 영상 설명란 표기.
4. **CC BY-NC 함정**: 수익화 채널은 상업 사용으로 보는 해석이 지배적 — **BY-NC 소재는 아예 배제**.
5. **PD여도 별개 권리**: 초상권/퍼블리시티권(식별 인물), 상표(로고), 기관 휘장. 다큐 서술 맥락은 일반적으로 안전, 광고성 맥락 금지.
6. **증거 보관(필수)**: 소재마다 `{파일 URL, 라이선스 페이지 URL, 종류, 확인 일자, Wayback 스냅샷}` 기록 — 라이선스는 바뀐다(Pixabay 2023, Unsplash 2017 실례). **다운로드 시점 증거가 방어막.** → `refs/asset-ledger.md`에 기록.
