# 크로스플랫폼 저작권·정책 지식 베이스 (2026-07-28 조사)

copyright-counsel(저작권 검수)·publisher(발행) 에이전트의 공용 지식 베이스.
대상: 한국 1인 창작자, YouTube·LinkedIn·네이버 블로그·티스토리·TikTok·Instagram Reels 동시 발행.

> ⚠️ **면책**: 일반 법률 정보이며 법률 자문이 아니다. 분쟁·고액 건은 저작권 전문 변호사 상담.
> 라벨: [사실]=1차 출처/교차확인 · [추정]=2차 출처 · [❓]=미검증. 플랫폼 정책은 **분기 1회 재검증**.

## 1. 음악

- [사실] **Content ID 클레임 ≠ 저작권 경고(strike)**. 클레임=자동 대조, 주로 수익만 권리자에게 이전, 채널 불이익 없음. strike=법적 삭제 요청, 영상 삭제+90일 제한, 3회 누적 시 채널 삭제.
- [사실] 이의 절차: Dispute(권리자 30일) → Appeal(7일) → 권리자가 정식 삭제요청 내면 strike 전환 가능 — **증빙 확실할 때만 appeal**. (support.google.com/youtube/answer/2797454, /12104471)
- 안전 수칙: 라이선스 음원만 사용 + **증서 보관** → 클레임 시 증서 첨부 dispute로 통상 해제.
- [사실] **틱톡 비즈니스 계정은 일반 음악 라이브러리 사용 불가**(CML만). 인스타 비즈니스도 Meta Sound Collection만. **두 라이브러리 권리는 해당 플랫폼 안에서만 유효** — 크로스포스팅 시 침해.
- [사실] LinkedIn은 자체 음악 라이브러리 없음 — 전 음원 자가 라이선스.
- [사실] "로열티프리" ≠ "저작권프리": 로열티프리=저작권은 살아 있고 이용권만 산 것(플랫폼·조건 제한 가능).
- **실무 결론**: BGM은 소스 라이선스형(Pixabay Music·Mixkit·CC-BY) 또는 자체 생성(ACE-Step, MIT)을 영상에 구워 전 플랫폼 동일 파일 배포.

## 2. 역사 사진·영상 (퍼블릭 도메인)

- [사실] **2026년 미국 PD 컷오프 = 1930년 발행작**(+1925년 음반). 매년 1월 1일 1년씩 전진.
- [사실] 미 연방정부 저작물(NASA·NARA)=미국 저작권 없음.
- [사실] **한국 보호기간 = 저작자 사후 70년**(저작권법 제39조). 업무상저작물=공표 후 70년.
- [사실] **URAA 함정**: 외국 저작물의 미국 저작권 자동 부활(17 USC §104A, Golan v. Holder 2012 합헌 유지) — 원산국 PD여도 미국은 아닐 수 있음.
- [사실] **이중 판정 원칙**: 글로벌 플랫폼 업로드 = 한국·미국 양쪽 PD만 안전. Commons의 한국 저작물 기준과 동일.
- [사실] Wikimedia는 라이선스 표기 무보증 — 재사용자 검증 의무.
- [사실] **뉴스 아카이브(AP·Getty·Reuters·방송사)는 옛 사건이어도 고위험** — 촬영물 저작권은 존속하고 권리 행사 적극적. 정식 라이선스가 원칙.

## 3. 공정이용

- [사실] 미국 4요소(목적·원저작물 성격·분량·시장 효과) / 한국 제28조(인용)+제35조의5(포괄 공정이용).
- [추정] 역사 채널: 짧은 클립+실질 해설·교육 목적이면 항변 여지 상당. 단 ①"짧으면 OK" 아님 ②공정이용은 사후 항변이지 사전 면허 아님 ③Content ID는 공정이용을 판단 못함.

## 4. AI 생성 콘텐츠

- [사실] **YouTube**: 현실 오인 가능한 합성 콘텐츠는 공개 토글 필수. **본인 목소리 클론 내레이션은 공개 의무 면제(공식 도움말 14328491 명시)**. 공개해도 도달·수익화 불이익 없음(공식). [❓ "2026 자동 AI 감지" 류 주장은 SEO 블로그발 — 미검증]
- [사실] **TikTok**: 사실적 AI 시각물·오디오 라벨 의무 + C2PA 메타데이터 자동 인식(2025-01~). 타인 목소리 사칭은 별도 위반.
- [사실] **Meta**: C2PA/IPTC 기반 "AI Info" 라벨 자동+수동.
- [사실] **AI 산출물 저작권**: 미국(USCO 2025-01 보고서)·한국(문체부 2025-06 안내서) 모두 — 인간 창작 개입 없는 순수 AI 산출물은 저작권 보호/등록 불가. → 내 AI 이미지는 남이 가져다 써도 막기 어려움. 차별화는 브랜딩·구성(인간 창작)에서.
- [사실] **Suno 무료 플랜 = 수익화 금지**(유료 전환해도 소급 안 됨). 생성 도구 무료 티어 상업권은 **사용 시점에 약관 직접 재확인**.

## 5. 플랫폼 간 재활용

- [사실] **틱톡 워터마크 영상을 릴스에 올리면 도달 억제**(역방향 동일). 대응: **워터마크 없는 원본 마스터를 각 플랫폼에 개별 업로드.** 자기 로고는 무방(Mosseri 공식).
- [사실] YouTube Shorts는 리믹스 opt-out 불가(올리는 순간 타인 리믹스 허용 구조).
- 음원 라이선스는 플랫폼을 따라가지 않음(§1).

## 6. 인물 — 초상권·퍼블리시티권 (한국)

- [사실] 부정경쟁방지법 (파)목(2022-06 시행): 널리 인식되고 경제 가치 있는 타인의 성명·초상·음성 무단 영업적 사용 = 부정경쟁행위.
- [사실/판례 갈림] 사망자: 초상권(인격권)은 사망으로 원칙 소멸, 퍼블리시티권 상속성은 판례 갈림.
- [추정] 실무 기준: ①오래전 사망한 역사 인물 사진의 **역사 서술·교육 맥락** 사용=저위험(사진 자체 저작권은 별도) ②생존 인물·최근 사망자·상품화 맥락(굿즈·광고)=고위험 ③명예훼손(사자 포함)은 별개로 항상 주의.

### 업로드 전 체크리스트
- 공통: 음원 라이선스가 이 플랫폼을 커버하는가 / PD는 한·미 양국 통과인가(URAA 포함) / 뉴스 아카이브 영상 미포함 / 인물 초상 점검 / AI 요소 라벨 준비.
- YouTube: 사실적 AI 요소 → 토글 ON(본인 음성 클론 면제). TikTok: 비즈니스면 CML만·C2PA 자동 라벨 전제. Reels: 비즈니스면 Sound Collection만·무워터마크 마스터. LinkedIn: 전 음원 자가 확인. 네이버·티스토리: 사전 필터 없음(사후 게시중단 요청 구조) — 동일한 사전 검증 적용.

### Content ID 클레임 대응 표준
1. 패닉 금지(클레임≠strike) → 2. 대장에서 해당 자산·증빙 조회 → 3. 증빙 있으면 Dispute(증서 첨부) → 4. 없거나 애매하면 음원 교체(유튜브 편집 도구) 또는 수용 → 5. 결과를 대장에 기록.
